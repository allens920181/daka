文案是設計材料，不是裝飾。

## 6.1 語氣

| 特徵 | 這樣寫 | 不這樣寫 |
| --- | --- | --- |
| **直白** | 還有 4 位沒到 | pending: 4 |
| **從使用者這一側** | 目前連不上網路 | Supabase RPC 逾時 |
| **不道歉** | 找不到這個房號。請確認有沒有打錯。 | 很抱歉，我們找不到… |
| **不誇張** | 全部到齊 | 太棒了！所有人都到齊了！🎉 |
| **具體優於聰明** | 房號不會用到 O、0 這些字元 | 房號格式有誤 |

不用驚嘆號。不用 emoji。不用「請稍候」以外的等待用語。

---

## 6.2 錯誤訊息的結構

**發生什麼 ＋（必要時）為什麼 ＋ 怎麼辦。**

| 情況 | 訊息 |
| --- | --- |
| 離線 | 目前連不上網路。你可以繼續點名，恢復連線後會自動上傳。 |
| 房號錯 | 找不到這個房號。請確認有沒有打錯。 |
| 房號含易混淆字元 | 房號不會用到 O、0 這些字元，請再確認一次。 |
| 非房主 | 只有開這間房的裝置可以做這件事。 |
| 房間已關閉 | 這間房已經關閉了。 |
| 未知錯誤 | 出了點問題，請再試一次。 |

「怎麼辦」沒有答案時就不要硬掰，但也不要用技術細節填空。

## 6.3 按鈕文案

- 動詞開頭：`複製連結`、`載入名單`、`刪除房間`。
- **與結果一致**：按「複製結果」之後 Toast 說「結果已複製」。
- 帶數量時用全形括號：`建立（12）`。
- 不用「確定 / 取消」以外的通用詞當破壞性動作的確認鍵——確認鍵要重複動作名稱（`刪除房間`），這樣就算沒讀說明也知道自己在按什麼。

## 6.4 命名慣例

| 對象 | 規則 | 例 |
| --- | --- | --- |
| CSS class | 小寫連字號，區塊在前 | `.member-name`、`.toast-action` |
| 變體 class | 獨立的修飾詞，與基底並用 | `class="btn btn-primary"` |
| 狀態 class | `is-` 前綴 | `.is-arrived`、`.is-excused` |
| Design token | `--<類別>-<階>` | `--fs-4`、`--st-pending` |
| i18n key | camelCase，依語意不依位置 | `missingCount` 而不是 `roomHeaderNumber` |
| 元件檔 | PascalCase `.tsx` | `Room.tsx`、`Sheet.tsx` |
| 邏輯檔 | camelCase `.ts` | `merge.ts`、`useModal.ts` |

**i18n key 依語意命名**很重要：同一個字串在兩個地方用到時，依位置命名的 key 會被複製成兩份，然後其中一份被忘記更新。

## 6.5 資料呈現

| 資料 | 規則 |
| --- | --- |
| 姓名 | 單行、超長以 `…` 截斷。**不縮寫、不只顯示姓** |
| 電話 | 儲存為純數字（`0912345678`），顯示也不加分隔符 |
| 時間（列上） | `HH:MM`，用裝置語系（`toLocaleTimeString`） |
| 時間（匯出） | `YYYY-MM-DD HH:MM:SS`，本地時區 |
| 日期（過期提示） | 裝置語系（`toLocaleDateString`） |
| 人數 | 一律 `tabular-nums`。**顯示人頭數（含攜伴）不是列數** |
| 房號 | 永遠大寫、等寬、不加分隔符 |

**人頭數 vs 列數**是這個產品最容易出錯的地方：遊覽車上要對的是人頭。凡是給使用者看的總數都是人頭數；只有「名單有幾列」才用列數（例如「建立（12）」）。

## 6.6 在地化

- **所有使用者可見字串都在 `src/lib/i18n.ts`。** 元件裡不得寫死中文。
- `zh` 是來源，`en` 由 TypeScript 強制必須有相同的鍵——少一個就編譯不過。
- **不得用字串拼接組句。** 用具名變數：`t('missingCount', { n: 4 })`，不是 `t('still') + n + t('missing')`。語序在不同語言不同。
- **英文比中文長約 30%。** 任何有文字的容器都要能容納 1.4 倍長度而不破版。按鈕標籤不換行，所以英文標籤要更短。
- 語言選擇**不影響**日期時間格式——那些跟隨裝置語系。語言不等於地區。
- 目前不支援 RTL。要支援的話，版面已經用 flex `gap` 而非固定 margin，主要工作會在圖示方向與 `padding-left/right`。

## 6.7 空狀態文案

空狀態要分辨「沒有資料」和「任務完成」：

| 情況 | 文案 |
| --- | --- |
| 「未到」篩選下沒有人 | **太好了，全部都到了** |
| 搜尋沒有結果 | 這裡沒有人 |
| 還沒有房間 | 還沒有房間。開一間，或用房號加入別人的。 |
| 還沒有常用名單 | 還沒有常用名單。名單載入後可以存起來，下次直接套用。 |

後兩者的共同點：**說明可以做什麼**，不只說「沒有資料」。
