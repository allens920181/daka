# 03 · Token

所有數值都必須來自這裡。要新增一階，先改這份文件並說明理由。
由 `src/styles.test.ts` 靜態檢查（原始碼）與 `scripts/design-audit.mjs` 執行期檢查（渲染結果）雙重把關。

---

## 3.1 色彩

色彩分**四層**，不得跨層借用。

分層的理由很實際：「未到」和「離線」色相接近，但一個是點名狀態、一個是系統回饋。
舊版兩者共用同一個 warn token，於是想把「未到」調醒目一點，離線指示就會跟著變。

### 表面與文字

| Token | 淺色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#f5f7f8` | `#0d1315` | 頁面底色 |
| `--surface` | `#ffffff` | `#151e21` | 卡片、列、輸入框 |
| `--surface-2` | `#eceff1` | `#1d282b` | 內嵌區塊、分段控制底 |
| `--surface-3` | `#dfe4e6` | `#263336` | 進度條底 |
| `--raised` | `#ffffff` | `#263336` | 浮在凹槽上的那一階（分段控制選中的那一格）|
| `--ink` | `#10171a` | `#e9eef0` | 主要文字（16.4:1／14.9:1） |
| `--ink-2` | `#4a5a5e` | `#a4b3b6` | 次要文字（7.6:1／8.2:1） |
| `--ink-3` | `#5f6f73` | `#8b9b9f` | 輔助文字、時間、計數（5.2:1／5.9:1） |
| `--rule` | `#d7dee0` | `#29373a` | 分隔線、預設邊框 |
| `--rule-strong` | `#b5c0c3` | `#3b4b4f` | 空狀態虛框、面板握把、列表項 hover 提示 |
| `--check-line` | `#7d8f93` | `#6b8085` | **未勾選的圈**（3.4:1／4.1:1） |

**「未到」的空心圈自己一個 token。** 它一度沿用 `--rule-strong`，而那只有
**1.86:1**——逆光下等於不存在，偏偏它是名單上唯一表示「這個人還沒上車」的形狀。
非文字的狀態指示要 3:1（WCAG 1.4.11），所以它不能跟「分隔線」共用色票：
分隔線可以很淡，狀態不行。

**`--ink-3` 是最淺的可用文字色。** 比它更淺的顏色不得用於文字——這條規則把原本的 `#7a8a8e`（3.34:1）擋掉了。

**深色模式的高度靠表面亮度，不靠陰影。** 深色底上的陰影幾乎看不見，所以層級越高的表面越亮（`--paper` → `--surface` → `--surface-2` → `--surface-3`）。

**這個階梯在明暗兩邊的方向是相反的**，所以「比某個表面高一階」不能寫死成某個
token。淺色是 `--surface`(白) > `--paper` > `--surface-2` > `--surface-3`，深色是
`--surface-3` > `--surface-2` > `--surface` > `--paper`。分段控制選中的那一格
一度直接用 `--surface`：淺色下比軌道亮 1.155:1（浮起來），深色下卻比軌道**暗**
1.12:1，而 `--el-1` 是純黑陰影在深底上等於不存在——被選到的那一格看起來反而像
沒被選到。`--raised` 就是為了這件事而存在：它的語意是「比 `--surface-2` 這種凹槽
高一階」，兩邊各自取對的值（實測改後深色 1.157:1，與淺色對稱）。

### 品牌與互動

| Token | 淺色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--accent` | `#0e5e63` | `#3fbfc7` | 主要按鈕底、選取邊框、**淡底上的強調文字** |
| `--accent-ink` | `#ffffff` | `#06232a` | 疊在 `--accent` 上的文字 |
| `--accent-soft` | `#e2f0f0` | `#11292c` | 強調用的淡底（chip、提示框） |
| `--accent-strong` | `#0c8a93` | `#5fd8df` | 焦點框。**不得用於一般文字** |

> `--accent-strong` 在淺色模式疊在 `--accent-soft` 上只有 3.54:1。淡底上的文字一律用 `--accent`（6.41:1）。

### 點名狀態

**只能用在名單成員的狀態**，不得用於系統訊息。

| Token | 淺色 | 深色 | 狀態 |
| --- | --- | --- | --- |
| `--st-pending` | `#a84d06` | `#e0913f` | 未到 |
| `--st-arrived` | `#1c7a44` | `#55bd7c` | 已到 |
| `--st-arrived-soft` | `#e3f2e8` | `#12291d` | 已到列的底色 |
| `--st-arrived-line` | `#a9d7bc` | `#2b5c3e` | 已到列的邊框 |

請假不給專屬色，用 `--ink-3` 加形狀（虛線圈 + 刪除線）。**請假不是待辦事項，不該吸引注意力。**

### 系統回饋

**只能用在系統訊息**，不得用於名單狀態。

| Token | 淺色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--fb-warn` | `#a84d06` | `#e0913f` | 離線、需要注意 |
| `--fb-warn-soft` | `#fbecdd` | `#2a2013` | 警告提示框底 |
| `--fb-error` | `#a02b22` | `#e5736a` | 錯誤、破壞性動作 |
| `--fb-error-soft` | `#f9e6e4` | `#2e1a18` | 錯誤提示框底 |

`--st-pending` 與 `--fb-warn` 目前是同一個值，但**是兩個 token**。哪天要把「未到」調得更醒目，不會連帶動到離線指示。

### Toast

Toast 是**獨立表面，不參與明暗反轉**。

舊版讓它反色（淺色用深底、深色用淺底），結果深色模式的「復原」按鈕只有 **1.45:1**——誤觸的安全網幾乎看不見。兩個 token 各自都合理，疊起來才壞掉。

| Token | 淺色 | 深色 | 對比 |
| --- | --- | --- | --- |
| `--toast-bg` | `#10171a` | `#1d282b` | — |
| `--toast-ink` | `#f5f7f8` | `#e9eef0` | 16.4:1／12.9:1 |
| `--toast-action` | `#5fd8df` | `#5fd8df` | 10.7:1／8.9:1 |
| `--toast-line` | `#10171a` | `#69868d` | 對 toast 底 3.9:1（深色） |

### Google 登入按鈕（第三方品牌，具名例外）

| Token | 淺色 | 深色 | 對比 |
| --- | --- | --- | --- |
| `--google-bg` | `#ffffff` | `#131314` | — |
| `--google-ink` | `#1f1f1f` | `#e3e3e3` | 16.5:1／14.5:1 |
| `--google-line` | `#747775` | `#8e918f` | 4.5:1／5.8:1 |
| `--google-bg-active` | `#f2f2f2` | `#1e1f20` | — |

這四個值來自 Google 自己的按鈕規範，**不是我們的色票**：不參與這個系統的任何
配色決定，也不得用在別的地方。理由見 [02-brand §2.5.1](02-brand.md)。

**深色模式的 Toast 靠邊框定義形狀。** `--toast-bg` 在深色是 `#1d282b`，只比它
蓋住的名單列亮 **1.12:1**——那塊「誤觸的安全網」在深色模式裡幾乎沒有實體。
淺色時深底自己就夠分明（18:1），所以 `--toast-line` 在淺色等於底色（等於沒有
邊框），只有深色真的畫出一條線。

### 遮罩與不透明度

| Token | 淺色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--scrim` | `rgba(9,16,18,.45)` | `rgba(0,0,0,.62)` | 模態層背景。深色要更重，否則深底上看不出層次 |
| `--op-disabled` | `.5` | 同 | 停用的按鈕 |
| `--op-muted` | `.62` | 同 | 請假的列：在場但不需要行動 |

### 對比要求

| 內容 | 最低 |
| --- | --- |
| 一般文字（< 24px，或 < 18.66px 粗體） | **4.5:1** |
| 大字（≥ 24px，或 ≥ 18.66px 且粗體） | **3:1** |
| 圖示、邊框等非文字資訊 | **3:1** |

淺色與深色**都要通過**。

## 3.2 字級

八階，不得新增。用 `px` 不用 `rem`——這是應用程式不是文件。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--fs-1` | 11px | 等寬微標籤（代碼、序號）。**唯一允許小於 13px 的用途** |
| `--fs-2` | 13px | 說明文字、時間、計數、chip |
| `--fs-3` | 15px | 內文、次要按鈕、選單項 |
| `--fs-4` | 17px | 成員姓名、主要按鈕、**所有輸入框** |
| `--fs-5` | 20px | 面板與對話框標題 |
| `--fs-6` | 26px | 畫面標題、代碼輸入 |
| `--fs-7` | 34px | 代碼大字 |
| `--fs-8` | 44px | 未到人數。**每個畫面最多一個** |

**輸入框一律 `--fs-4`（17px）。** iOS Safari 對小於 16px 的輸入框會自動放大整個頁面——在點名途中發生這件事非常煩。

行高：內文 1.55、標題 1.25、說明 1.6。標題一律加 `text-wrap: balance`。

數字對齊：任何會排成欄的數字都要 `font-variant-numeric: tabular-nums`。

## 3.3 間距

以 4px 為基準，七階。

| Token | 值 | 典型用途 |
| --- | --- | --- |
| `--sp-1` | 4px | chip 之間、圖示與文字 |
| `--sp-2` | 8px | 列表項之間、按鈕內間距 |
| `--sp-3` | 12px | 元件內距、堆疊間距 |
| `--sp-4` | 16px | 頁面左右內距、卡片內距 |
| `--sp-5` | 24px | 區塊之間 |
| `--sp-6` | 32px | 大區塊之間 |
| `--sp-7` | 48px | 空狀態的上下留白 |

不得出現不在階上的值。例外只有：邊框（1px / 2px）、以及少數結構性尺寸（列高、最大寬度），那些在 `src/styles.test.ts` 有白名單。

## 3.5 陰影

三階，不得自訂。

| Token | 用途 |
| --- | --- |
| `--el-1` | 卡片、分段控制裡浮起的那一段 |
| `--el-2` | 底部動作列（往上打光） |
| `--el-3` | 面板、對話框、Toast |

深色模式的陰影更深，但主要靠表面亮度表達層級（見 3.1）。

## 3.6 動態

| Token | 值 | 用在什麼 |
| --- | --- | --- |
| `--dur-1` | 120ms | 按壓回饋（`scale(.98)`）、hover |
| `--dur-2` | 200ms | 面板／對話框／Toast 進場、進度條、狀態色變化 |
| `--dur-3` | 320ms | 較大位移（目前未使用，保留） |
| `--dur-ambient` | 1100ms | 持續性指示：同步中的脈動、載入骨架的呼吸 |
| `--ease` | `cubic-bezier(.2,.8,.3,1)` | 全部。**不得自訂 easing** |

**全部動態都必須被 `prefers-reduced-motion: reduce` 關閉。**

不動的東西：名單列的出現與消失（篩選切換時不做動畫——列在動會讓人點錯）、數字變化（直接換，不做滾動計數）。

## 3.7 層級

只有四層，不得插值。

| Token | 值 | 誰 |
| --- | --- | --- |
| `--z-sticky` | 20 | 頂欄 |
| `--z-dock` | 30 | 底部動作列 |
| `--z-modal` | 40 | 面板、確認對話框的遮罩層 |
| `--z-toast` | 50 | Toast |

**Toast 永遠在最上層**，因為它可能是唯一的復原機會——即使面板開著也要看得見。

**但「看得見」不等於「可以擋住東西」。** Toast 平常貼在下緣 88px 處讓開底部動作列，
而面板也是從下緣長上來的，於是它正好落在選單列之間：實測蓋住「更多」面板的
「結束這一輪」49px，而 `.toast` 是 `pointer-events: auto`，那五秒內那一列按不下去；
深色下更難察覺它是外來的，因為 Toast 底色和 `.menu-item:hover` 同一個
`--surface-2`。所以模態層開著時（`useModal` 會在 `<html>` 掛 `data-modal`）
Toast 改貼上緣的遮罩區——面板最高 88vh，上面那一條本來就沒有東西可以按。
`scripts/e2e-local.mjs` 驗它不蓋住任何選單列、也不攔截任何一列的點擊。

## 3.9 圖示

| 規格 | 值 |
| --- | --- |
| 網格 | 24 × 24 viewBox |
| 線寬 | 2（不隨尺寸改變） |
| 端點與轉角 | `round` |
| 填色 | 一律 `none`，只用 `stroke="currentColor"`。實心點是唯一例外 |
| 尺寸 | **只有三種**：16（內嵌於文字）、20（一般按鈕）、24（頂欄） |

尺寸由元件的預設值決定，**呼叫端不得覆寫**（`IconShare` 的型別只接受 `16 | 20 | 24`）。

新增圖示的規則：先找現有的能不能用；線條風格必須與既有一致；不得引入圖示庫（會把用不到的部分打包進來）。全部圖示在 `src/ui/icons.tsx`。
