# 元件 · 點名

這一組是產品的核心。改動之前先讀 [01 基礎](../01-foundations.md)。

### 名單列 `.member`

**用途** — 顯示一個人，並讓人一觸切換未到 ⇄ 已到。

**不要用在** — 任何不是「點名對象」的清單（常用名單、最近的房間用 `.recent-item`）。

**解剖**

```
.member
├─ .member-main   ← 整片可點，觸發狀態切換
│   ├─ .check         勾選圈（30px）
│   └─ .member-body
│       ├─ .member-name
│       └─ .member-meta   chip 與時間
└─ .member-side   ← 不觸發切換
    ├─ 撥號鍵（只在「未到 + 有電話」時出現）
    └─ 更多
```

**狀態** — 三種，**顏色與形狀都要不同**。逆光下顏色會失真，色盲者看不出色相。

| 狀態 | 底色 | 圈 | 文字 |
| --- | --- | --- | --- |
| 未到 | `--surface` | 空心圓，`--rule-strong` 邊 | 正常 |
| 已到 | `--st-arrived-soft`，邊框 `--st-arrived-line` | **實心圓 + 勾** | 正常，附時間與點名者 |
| 請假 | `--surface`，整列 `--op-muted` | **虛線圓** | 刪除線 |

**互動規則**

- 整列可點是刻意的：現場要快。代價是誤觸，用 **5 秒無條件復原**補償。
- **不得加入滑動手勢。** 滑動刪除／滑動標記在這個清單上是危險的——捲動找人時很容易誤觸，而誤觸的代價是有人被留在原地。
- 房間關閉時 `.member-main` 停用，但列仍可讀。**關閉是全域狀態，不能只靠一條
  會捲走的橫幅**：頂欄的計數位置要換成「已關閉」，否則捲到名單深處時戳名字
  沒反應，協助者完全不知道為什麼。
- 篩選切換時不做動畫。列在動會讓人點錯。

**內容規則** — 姓名單行、超長以 `…` 截斷（完整姓名在成員面板可看）。名單順序在所有裝置上必須一致（依 `sort_order`，其次 `created_at`，最後 `id`）。

- **狀態不得在 meta 裡重複一次。** 名單常寫成「陳大同（請假）」，於是 note 是
  「請假」而狀態也是請假；兩個都印就會出現「請假 請假」，螢幕與紙本都是。
  note 整則等於狀態詞時不印 note（`isExcusedNote()`）——但「請假 已交假單」
  這種帶額外資訊的備註仍要印。
- **名單裡有同名的人時，那些列要多印一段辨識資訊**（`.chip-tell`：分車，
  沒分車就用電話尾四碼）。兩列一模一樣的「陳怡君」在現場無法分辨，而其中
  一位被標成已到之後還會被狀態篩選藏起來。沒有同名的人不加這個晶片——
  它存在的唯一理由就是消除歧義。

**無障礙契約**

- `.member-main` 是 `<button>`，帶 `aria-pressed={已到}`。
- `aria-label` 描述**按下去會發生什麼**：「王小明 · 標記已到」，不是「王小明 · 已到」。
- 撥號鍵是 `<a href="tel:">`，`aria-label` 為「打電話給王小明」。
- 兩個右側目標各 48px，彼此間距 `--sp-2`（8px）。`.member-side` 與整列的切換
  熱區之間要有 `border-left` 分隔：撥號鍵整場點名都在，而它就貼在「整列＝
  切換已到」的熱區旁邊，拇指往右偏一點就變成打電話給人家。

**實作** — `src/ui/Room.tsx`（`MemberRow`）

### Chip `.chip`

**用途** — 附在姓名旁的一小段結構化資訊。

**不要用在** — **點名狀態**。狀態由列本身表達（見上）。用 chip 表達狀態會跟「備註剛好寫請假」的情況撞在一起。

**變體** — 三種語意，不得混用。

| 類別 | 樣式 | 內容 |
| --- | --- | --- |
| `.chip-count` | `--accent-soft` 底、`--accent` 字 | 攜伴人數 `＋2` |
| `.chip-note` | `--surface-2` 底、`--ink-2` 字 | 名單上的備註 |
| `.chip-data` | `--surface-2` 底、等寬 | 電話等資料 |
| `.chip-tell` | `--accent-soft` 底、`--accent` 字、700 | **只在有同名的人時出現**的辨識資訊 |

**內容規則** — 一列最多三個 chip，超過的收進成員面板。chip 不換行、不截斷（內容本來就該短）。

**實作** — `src/styles.css`

### 計分區 `.scoreboard`

**用途** — 一眼看到「還有幾位沒到」與「已到人頭 / 總人頭」。

**不要用在** — 顯示其他統計。這裡只放這兩個數字。

**解剖**

```
.scoreboard
├─ .score-main
│   ├─ .score-number   未到人數，--fs-8
│   │   └─ .score-done 全到齊時改印「全部到齊」，--fs-7
│   └─ .score-text
│       ├─ .score-label  「位沒到」（單位，不重複數字）
│       └─ .score-scope  選了分組時的分組名
└─ .score-heads        「3 / 14 人」
.progress-row
├─ .progress           進度條
└─ 複製結果按鈕
```

**規則**

- 未到人數是全畫面唯一的 `--fs-8`。
- **大數字與標籤不得重複同一個數字。** 標籤只寫單位（「位沒到」），因為數字
  已經以 44px 印在它左邊。把「還有 N 位沒到」整句放進標籤，等於在 8px 外把
  同一個數字寫第二次。
- **全到齊時不印那顆「0」。** `.score-number` 換成 `.score-done` 印「全部到齊」，
  字級降到 `--fs-7`、顏色 `--st-arrived`。「0 全部到齊」會讓人愣一下。
  空名單（`people === 0`）不算全到齊，只是還沒有人。
- **右側是人頭數不是列數**——遊覽車上要對的是人頭。
- **分母是 `expectedHeadcount`（扣掉請假者與其攜伴），不是 `headcount`。**
  進度條、`.score-heads`、看板、貼回 LINE 的文字都適用。用名單總人頭當分母，
  只要有人請假，全到齊時就會顯示「15 / 16」配一條填不滿的進度條。
- **選了分組時，數字必須自己說是哪一組**（`.score-scope`；頂欄接手時是
  `.topbar-scope`）。否則「還有 3 位沒到」在全隊和第一車是同一句話。
- **捲出畫面時頂欄必須接手顯示**（`.topbar-count`）。這個數字不能消失。

**無障礙契約** — 進度條 `role="progressbar"` + `aria-valuenow/min/max` + `aria-label`（帶實際人數，不只是百分比）。

**實作** — `src/ui/Room.tsx`

### 分段控制 `.segmented`

**用途** — 在互斥的檢視之間切換（全部／未到／已到／請假）。

**不要用在** — 超過四段，或段數會頻繁變動的情況。

**規則**

- 每段最小高 48px。
- 段數是 3 或 4（有人請假時才出現第四段），**第四段永遠在最後**。
- 容器可橫向捲動且不換行（`overflow-x: auto`），窄螢幕不擠壓。
- 每段顯示計數；選取那段的計數用 `--accent`，其餘用 `--ink-3`。

**無障礙契約** — 每段是 `<button aria-pressed>`，容器 `role="group"` 加 `aria-label`。
**不要**用 `role="tablist"`——它沒有對應的 tabpanel 結構。

**實作** — `src/ui/Room.tsx`（`Segment`）

### 分組選擇器 `.groups`

**用途** — 在分車／分組之間切換。一趟旅遊常有兩三台車，顧第一車的人要看的是「我這台還有幾個沒上」。

**不要用在** — 狀態切換（那是分段控制）。分組是「看哪一群人」，狀態是「看哪一種狀態」，兩個維度是 AND 關係。

**規則**

- **只在名單真的有分組時出現。** 沒分組就不該多一列控制項。
- 第一個永遠是「全部」。
- 每個晶片右邊顯示**那一組還有幾位沒到**，全到齊時轉綠。
- 選了某一組之後，**計分區、進度條、篩選計數、複製結果全部只算那一組**。這是重點：顧第一車的人不該被第二車的數字干擾。
- 容器可橫向捲動，不換行。晶片最小高 48px。
- 名單被換掉導致目前選的分組不存在時，自動退回「全部」。

**無障礙契約** — 每個晶片是 `<button aria-pressed>`；`aria-label` 要包含該組的到齊狀況，因為視覺上的數字沒有標籤。

**實作** — `src/ui/Room.tsx`

### 分組分隔 `.group-divider`

**用途** — 看「全部」時標出分組交界，現場才知道哪裡是第二車的開頭。

**規則** — 只在 `groupList.length > 0` 且未選特定分組時出現。沒有分組的人歸在「未分組」。列印時變成粗體小標題並加 `break-after: avoid`。

**實作** — `src/ui/Room.tsx`

### 同步指示 `.sync`

**用途** — 永遠告訴使用者資料在不在雲端上。

**不要用在** — 任何會消失的地方。它必須一直在頂欄。

**狀態** — 四種，各有專屬顏色與文字。

| 狀態 | 顏色 | 文字 |
| --- | --- | --- |
| `online` | `--st-arrived` | 已同步 |
| `syncing` | `--accent` | N 筆待上傳 |
| `offline` | `--fb-warn` | 離線中 · N 筆待上傳 |
| `local-only` | `--ink-3` | 單機模式 |

### 分組晶片 `.group-chip`

**用途** — 把名單切到「我這一台車」。顧第一車的志工要看的是「我這台還有幾個沒上」，不是全隊的數字。

**規則**

- **有分組時，「未分組」必須也是一個晶片。** 名單上總有幾個沒填車次的人；
  沒有這個晶片的話，兩個顧車的志工各自選了自己那一車，就沒有人負責他們。
  同理，看「全部」時第一段（沒有分組的那一段）也要有 `.group-divider` 標題。
- 內部值用哨符（`'\u0000ungrouped'`）而不是 `null`——`null` 已經是「看全部」
  的意思，兩者必須分得開。畫面上一律顯示 `t('ungrouped')`。
- 選了分組之後，**計分區與頂欄接手的計數都要印出分組名**（`.score-scope` /
  `.topbar-scope`）。否則「還有 3 位沒到」在全隊和第一車是同一句話。

**無障礙契約** — 每個晶片 `aria-pressed` 表示是否選中，`aria-label` 帶實際人數（`groupCount`）。

**實作** — `src/ui/Room.tsx`、`src/ui/Board.tsx`

**規則** — `syncing` 的圓點可脈動（`--dur-ambient`），必須被 reduced-motion 關閉。
**不得**只用圓點顏色表達狀態，一定要附文字。

**實作** — `src/ui/Room.tsx`（`SyncBadge`）
