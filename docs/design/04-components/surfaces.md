# 元件 · 表面

### 頂欄 `.topbar`

**用途** — 空間身分、同步狀態、以及兩個全域動作。

**解剖**

```
.topbar-inner
├─ 返回（icon-btn 24）
├─ .topbar-title
│   ├─ .topbar-name   空間名稱，單行截斷
│   └─ .topbar-sub    代碼 或 .topbar-count ＋ 同步指示
├─ 分享（icon-btn）
└─ 管理（icon-btn）
```

**規則**

- `position: sticky`、`--z-sticky`、上方留 `env(safe-area-inset-top)`。
- 副標平常顯示**代碼**；空間關閉時換成「已關閉」（`.topbar-count`）——關閉是全域狀態，不能只靠一條會捲走的橫幅。
- **篩選與搜尋都住在頂欄裡**，所以跟著黏住。未到人數就在篩選那排（「未到 N」），不需要另一套「捲出畫面時接手」的機關。
- **標題可點，點了回到名單頂端**（`aria-label` 用 `backToTop`）。200 人的名單捲到底之後，要回到搜尋框得往上滑 17 個螢幕，而 `overscroll-behavior-y: none` 連「用力甩」都擋掉了。這是行動裝置的既有慣例，不必再教。
- 頂欄最多兩個圖示動作。第三個以上收進管理面板。

**實作** — `src/ui/Room.tsx`

### 卡片 `.card`

**用途** — 把一組相關的控制項圈在一起（例如首頁的「加入空間」）。

**不要用在** — 名單項目。列表用 `.member` 或 `.recent-item`，它們有各自的觸控規則。

**規則** — `--surface` 底、`--rule` 邊框、`--r-3` 圓角、`--el-1` 陰影、`--sp-4` 內距。不巢狀。

**實作** — `src/styles.css`

### 代碼大字 `.code-display`

**用途** — 在分享面板裡把代碼顯示到隔著一支手臂也唸得出來。

> **分享面板還有一區「現在在這個空間裡」**（雲端模式、且 presence 真的通了才
> 顯示）。規則見 05-patterns §5.10.1——重點是 **REST 通了不代表 presence 通了，
> 沒把握就整區不顯示**，絕不能在別人明明已經進來時說「目前只有你」。
>
> **單機模式下整個分享面板換掉。** `connection === 'local-only'` 時不渲染
> `.code-display`、不渲染 `.qr-card`、不給連結按鈕，面板標題改成「這個空間只有
> 你看得到」，內容改成一塊 `.note-warn` 說明別人會看到什麼。發出去的代碼在
> 這個模式下對任何人都沒有用——五個同工會在車門口看到「找不到這個代碼。
> 請確認有沒有打錯」，然後以為是自己打錯而重試三次。見 01-foundations §1.2
> 原則 5 的第 1 條。

**規則** — 等寬、`--fs-7`、字距 `.18em`、置中。字距造成的視覺偏移用左右不等內距補償。

**內容規則** — 永遠大寫，永遠不加分隔符（`K7F2QM` 不寫成 `K7F-2QM`）——使用者會照著打，多一個符號就多一次打錯。

**實作** — `src/ui/Sheets.tsx`

### QR 卡片 `.qr-card`

**用途** — 讓協助者掃碼加入。

**規則**

- **一律白底黑碼，即使深色模式。** 掃描器要的是對比。
- 這是全系統唯一允許寫死 `#fff` 的地方，例外寫在 `src/styles.test.ts`。
- 最大寬 240px（更大不會更好掃，只會佔掉面板空間）。
- 產生失敗時安靜降級——代碼與連結仍可用，不顯示錯誤。

**無障礙契約** — `<img>` 的 `alt` 要包含代碼，讓看不到 QR 的人也拿得到資訊。

**實作** — `src/ui/Sheets.tsx`（`ShareSheet`）

### 標籤 `.tag`

**用途** — 標示身分或分類，例如「我開的」／「協助點名」。

**不要用在** — 名單成員的附加資訊（那是 chip）。tag 是身分，chip 是屬性。

**變體** — `.tag`（中性）、`.tag-owner`（`--accent-soft` 底、`--accent` 字）。

**規則** — 藥丸形、`--fs-2`、不可點擊。要可點就不是 tag 了。

**實作** — `src/ui/Home.tsx`
