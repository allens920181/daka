# 元件 · 回饋

### 空狀態 `.empty`

**用途** — 名單為空或篩選後沒有結果時，說明為什麼、以及可以做什麼。

**規則** — **沒有框**、置中、`--sp-7` 上下留白。**不放插圖**（見 [02 品牌](../02-brand.md)：不搶戲）。

> 它 2026-09 之前是「白底 ＋ 虛線框 ＋ `--r-3` 圓角」。那是全站唯一一處虛線，也是
> 唯一一個用 `--r-3` 的非覆蓋層元件——一句「這裡什麼都沒有」，卻長成名單畫面上
> 視覺最特殊的一塊。**空狀態不需要一個框來證明自己是空的。**

**內容規則** — 空狀態要分辨「沒有資料」和「任務完成」：

| 情況 | 文案 |
| --- | --- |
| 「未到」篩選下沒有人**且搜尋框是空的** | **「太好了，全部都到了」** — 這是成功，不是空 |
| 搜尋沒有結果 | 「這裡沒有人」＋副行「還有 N 位沒到，換個字再找找」 |
| 沒有最近的空間 | 「還沒有開過空間。開一個，或用代碼加入別人的。」 |

> **搜尋字串優先。** 只要搜尋框有字，就一律走「搜尋沒有結果」那一列，即使
> 目前在「未到」篩選下。「太好了，全部都到了」在這個產品裡等於「可以關門
> 了」，而它最容易出現的時機正好最危險：收尾、車門邊、單手打注音打錯字。
> 打錯字的人該看到的是「沒找到」，不是「不用找了」。

**實作** — `src/ui/Room.tsx`、`src/ui/Home.tsx`

### 載入骨架 `.skeleton-row`

**用途** — 進入空間時顯示即將出現的形狀。

**不要用在** — 少於 300ms 的等待（閃一下比等待更擾人），或不確定會出現什麼的情況。

**規則** — 五列，高度等於 `--tap-row`，依序延遲 90ms 呼吸（`--dur-ambient`）。reduced-motion 下不動但仍顯示。

**無障礙契約** — 容器 `role="status"` + `aria-busy="true"` + `aria-label`；骨架本身 `aria-hidden="true"`。

**實作** — `src/ui/Room.tsx`（`RoomSkeleton`）

### 提示框 `.note` / 頁面說明 `.page-note`

**用途** — 就地說明狀況。`.note` 是一個**凹槽**，貼在相關控制項旁；`.page-note` 是頁面層級的一句話，站在畫面最上面。

**變體**

| 類別 | 底 / 字 | 用途 |
| --- | --- | --- |
| `.note` | `--surface-2` / `--ink-2` | 中性說明 |
| `.note-warn` | `--fb-warn-soft` / `--fb-warn` | **一件事要先知道**：名單有重複姓名、單機模式的代碼發出去沒有用、這個瀏覽器開不了相機 |
| `.note-error` | `--fb-error-soft` / `--fb-error` | **一個動作失敗了**：加入空間失敗、登入失敗、找不到代碼 |

> **warn 與 error 的分工 2026-09 配色重構才真的成立。** 在那之前 `.note-error` 是
> **死程式碼**：全 app 十四處「失敗了」的訊息掛的都是 `.note-warn`，而 `--fb-warn`
> 又跟「未到」是同一個十六進位值——於是「加入失敗」與「還有 4 位沒到」在畫面上
> 是同一個顏色。現在三個暖色各站一個位置（見 [03 Token](../03-tokens.md) 的暖色
> 斜坡），而**錯誤訊息終於看起來像錯誤訊息**（§2.3 的「直白」）。
>
> 判準是一句話：**這是「做不到」還是「先跟你說一聲」？** 前者 error，後者 warn。
| `.page-note` | **無底色** / `--ink-2` | 資訊：單機模式。有色底是在說「這裡不一樣」，而這一種只是補一句背景說明——`--surface-2` 疊在 `--paper` 上只差 1.09:1，那個填色沒有框住任何東西，只是在首頁最上面放了一塊三行高的灰方塊，比它底下的主要動作還早被讀到（2026-09） |

> **`.banner` 這個類型 2026-09 形狀重整移除。** 它最後只剩兩個變體，而兩個都不想
> 當橫幅：`.banner-warn` 隨結果橫幅改版一起走了，`.banner-result` 是一張卡片
> （現在是 `.result-card`，見 [表面](surfaces.md)），`.banner-muted` 是一句話——
> 它把 `.banner` 給的底色與內距全部覆寫成透明與 0，只留下 flex 與下邊距。
> **一個類型的變體如果各自把它給的東西退掉，那它就不是一個類型**（通則 7）。
> 兩邊各自拆成自己完整的東西：卡片是 `.result-card`，話是 `.page-note`。

**內容規則** — 錯誤一定要含「怎麼辦」。詳見 [06 內容](../06-content.md)。

**實作** — `src/styles.css`
